# mole컴퍼니 홈페이지

순천·여수·광양 소상공인 스레드 마케팅 **mole컴퍼니** 홈페이지입니다.

- 주소: https://molezzang.github.io/mole/
- `index.html` 파일 하나로 된 정적 사이트입니다. (로고 `logo.png`, 링크 미리보기 이미지 `og.png`)

## 자주 바꿀 곳 (index.html 안)

| 바꿀 것 | 찾을 단어 |
|---|---|
| 카카오톡 오픈채팅 링크 | `const CONFIG` 의 `kakao: ''` 따옴표 안에 링크를 넣으면 상담 버튼이 전부 카카오톡으로 바뀝니다 |
| 상품 · 가격 · 설명 | `const PRODUCTS` |
| 작업 사례 | `const CASES` |
| 자주 묻는 질문 | `const FAQ` |

후기 섹션은 실제 후기가 생기면 추가합니다.
